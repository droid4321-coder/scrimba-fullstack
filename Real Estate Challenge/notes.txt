Super Challenge

Each card should have an image, a property location ,a price, a comment, and the total property size in square metres
(each object has an array with the size in square meters of the individual rooms.)

If no arrays is passed to getPropertyHtml, th eplaceholder property stored in placeHolderPropertyObj in the properties foler should be rendered instead
