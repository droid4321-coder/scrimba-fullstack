L4 - Aside - usePathname()
Lets see how to put active links. Its applied when we are on the page. Its not only applying CSS, rather use a Next.js hook called usePathname(), which reads the current pathname and we can have it in a variable. Since this only works on a client component, the hook, we must include the words "use client" on the initial .tsx file. the use client tells next.js that this will be rendered client side. Now we can apply this variable to do some conditional styling to the active component.
