L4 - Routing in Next.js
Adding new pages to the site, a route is a URL path that maps to a page in our app. We do them in next.js by adding folders and a file called page.jsx/tsx in it. Tha folder needs to be inside the app directory.

Chart of Routing

directory structure, url path/route, description, full URL
app/page.tsx, /, homepage, localhost:3000/
app/about/page.tsx, /about, about page, localhost:3000/about
app/products/page/tsx, /products, products list page, localhost:3000/products
