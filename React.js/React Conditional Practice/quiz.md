# What is "conditional rendering"? -> Conditional rendering is a way to determine if content should be shown or not depending if it meets a condition

1. When would you use &&? -> I would use it when I need to simply determine if a content is shown or not, and dont need to modify the contents of said element
2. When would you use a ternary? -> I would use a ternary if I need to change the content of the item.
3. What if you need to decide between > 2 options onwhat to display? -> In this case I can use either a nested ternary, or multiple if else statements, or a switch statement.
